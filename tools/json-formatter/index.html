JSON Formatter & Validator

How this JSON formatter works

      
Paste any JSON object or array into the input box above. Format pretty-prints it with your chosen indent; Minify strips all whitespace down to the smallest valid representation. Both run through the browser's own JSON.parse first, so if the input isn't actually valid JSON, you get a real parser error rather than a formatter guessing at your intent.

      
Common JSON mistakes this catches

      
    
        
  • Trailing commas after the last item in an object or array — valid in JavaScript object literals, invalid in JSON
    • 
        
  • Single quotes instead of double quotes around strings and keys — JSON requires double quotes, no exceptions
    • 
        
  • Unquoted object keys ({name: "x"} instead of {"name": "x"})
    • 
        
  • A missing comma between array/object entries, or a missing closing brace or bracket
    • 
        
  • undefined, comments, or a bare function used as a value — none of these exist in the JSON spec, even though they're legal JavaScript
    • 
      

      
Reading the error message

      
When parsing fails, the banner reports the exact line and column where the browser's parser gave up — for example, a trailing comma before a closing ] is reported at the position of the ] itself, since that's where the parser expected another value and found the end of the array instead. It won't tell you "line 12 has a trailing comma" directly, but knowing the exact position turns a search through a large payload into a single jump to the right spot.

      
Worked example

      
Paste {name:'Ada', tags:['x','y',],} and Format will report a parse error, because none of unquoted keys, single quotes, or trailing commas are valid JSON — even though every one of those is perfectly legal in a JavaScript object literal, which is where this input most often comes from (copying an object straight out of source code instead of a real JSON payload). The valid form is {"name": "Ada", "tags": ["x", "y"]}.

      
Nothing you paste here is sent anywhere — parsing and formatting both run locally, using the browser's built-in JSON.parse/JSON.stringify, the same functions any JavaScript runtime uses under the hood.
