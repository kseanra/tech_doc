What is a Unix timestamp?

      
A Unix (epoch) timestamp counts seconds — or milliseconds, depending on the system — since 00:00:00 UTC on 1 January 1970. Databases, logs, and APIs frequently store time this way because it's a single unambiguous integer with no timezone attached to misinterpret; the timezone only enters the picture when you're ready to display the value to a person, which is exactly what this page's four output rows do.

      
Why four different outputs for the same moment in time

      
A timestamp itself has no timezone — 1700000000 is the same instant everywhere on Earth. Local time renders it in your browser's own timezone (whatever your operating system is set to); UTC renders the same instant with no offset applied, which is what you want when comparing values across a distributed system where "local" would mean something different on every server; ISO 8601 is the unambiguous machine-readable string format (2023-11-14T22:13:20.000Z) that most APIs expect when you need to send a date as text; and Relative ("3 months ago", "in 2 days") is the human-friendly framing you'd put in a UI, computed against the current time.

      
Worked example

      
Enter 1700000000 with unit set to seconds, and the four rows show the same instant four ways — useful for confirming, say, that a timestamp your API returned really does correspond to the date you expect, in the timezone your users will actually see it in.

      
Seconds vs. milliseconds — check this first

      
The single most common reason this tool shows a wildly wrong date (usually 1970 itself, or several decades in the future) is picking the wrong unit. JavaScript's own Date.now() returns milliseconds, while most server languages, database columns, and API conventions use seconds — mixing the two up by a factor of 1000 is an easy and extremely common bug. If your result year looks obviously wrong, flip the unit dropdown and try again before assuming the timestamp itself is bad. If what you actually need is just the current timestamp rather than converting a specific date, the narrower Unix Timestamp tool is built specifically for that, with a live-updating clock instead of a conversion form.
